# Demonstration script — approximately 45–60 seconds

Prepare the seven-step workflow from [the walkthrough](demo_workflow.md) before
recording. Use the synthetic CSV only. Start with the original overview visible;
the configured steps may already be collapsed below. Do not suggest that all setup
was performed during the recording. Speak at approximately 130–150 words/minute.
The narration is 118 spoken words (approximately 47–55 seconds at that pace), plus
brief transitions. It is a script, not a claim that a video has been recorded.

| Time | Real interface action | Narration |
| --- | --- | --- |
| 0–10 s | Show title and original overview; briefly point to metrics. | “Smart Data Processor is my personal Python portfolio project for cleaning CSV and Excel data locally. This fictional sales file contains twelve rows, three missing cells, and two duplicate rows.” |
| 10–24 s | Scroll to the prepared queue; expand text cleaning, median and date settings. | “I’ve configured an ordered workflow to trim text, normalize case, remove duplicates, convert numbers, fill missing values, and standardize dates. Date formats are explicit, and the original dataset stays unchanged.” |
| 24–40 s | Select Preview changes; show Results and side-by-side tables. | “Before applying anything, I review the preview. The result has ten rows, no missing cells, and no duplicates. The report explains each operation, so the changes can be checked.” |
| 40–55 s | Check review confirmation; apply; prepare downloads and show all three buttons. | “After confirmation, I can download CSV, Excel, and a JSON report. Flat Excel exports protect formulas as text; the unchanged original workbook is the option for preserving workbook functionality.” |

Keep actual export warnings visible. Do not add invented charts, fabricated speed
comparisons, client logos, revenue claims or a production-deployment claim. If the
recording runs longer, shorten pauses rather than implying an unmeasured speedup.
