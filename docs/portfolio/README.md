# Portfolio materials

## Short project summary

Smart Data Processor is a local Python application for inspecting and cleaning
CSV and Excel datasets. Its Streamlit interface wraps a reusable pandas/openpyxl
engine, with ordered transformations, review-before-apply controls and documented
export safeguards. A synthetic sales example makes the workflow reproducible.
This is a personal software portfolio project, developed with assistance from
OpenAI Codex; it is not presented as a customer engagement or production deployment.

**Project description:**

Smart Data Processor is a personal portfolio project for cleaning CSV and Excel data locally. Built with Python, pandas, openpyxl and Streamlit, it supports missing-value handling, duplicate removal, text cleanup, numeric conversion and explicit date formats. Users review changes before applying them, then export CSV, XLSX and JSON reports. The modular engine has automated regression tests and formula-safe exports. The demo uses fictional data; this is not a client deployment or a claim of commercial use.
